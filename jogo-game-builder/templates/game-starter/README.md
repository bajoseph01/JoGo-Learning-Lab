# Jo⚡Go Game Starter

A lightweight static-web scaffold for rapid educational game prototyping.

## Start here

1. Edit `GAME_SPEC.md`.
2. Replace placeholder game content in `data/content.js`.
3. Implement the smallest learning loop in `src/game.js`.
4. Use the built-in DEV panel immediately during testing.
5. Do not begin premium visual polish until the mechanic is approved.

## Run

Opening `index.html` directly works for simple prototypes. For full browser behaviour, use any static local server.
