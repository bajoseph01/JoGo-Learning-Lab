# Jo⚡Go Game Builder Pack

A reusable build system for Grade 4–7 educational web games.

## Purpose

This pack exists to stop every new game from rediscovering the same decisions. It encodes the build sequence, visual-quality gates, educational-geometry rules, iPad QA, DEV mode, and a reusable static-web scaffold.

## Recommended workflow

1. Copy `templates/game-starter/` into a new game folder.
2. Complete `GAME_SPEC.md` before serious implementation.
3. Build only the smallest playable learning loop.
4. Declare `CORE LOOP LOCKED` before premium visual work.
5. Approve one visual direction and treat it as authoritative.
6. Rebuild/polish using the approved visual system.
7. Use DEV MODE to jump directly to every state during QA.
8. Run the iPad QA checklist and educational-geometry checks.
9. Only then prepare the GitHub Pages classroom build.

## Key rule

> Academic knowledge must become part of the game's operating system, not a quiz pasted on top of a game.
