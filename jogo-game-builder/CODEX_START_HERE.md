# Codex — Start Here

Before implementing a Jo⚡Go game:

1. Read `skills/jogo-game-builder/SKILL.md`.
2. Read all files in `standards/`.
3. Copy `templates/game-starter/` into the new game folder.
4. Complete `GAME_SPEC.md`.
5. Build only the smallest playable learning loop.
6. Stop and request approval before premium visual work unless `CORE LOOP LOCKED` is already recorded.
7. Do not polish without an approved visual direction.
8. Keep DEV MODE available throughout development.
9. Treat educational diagrams/instruments as functional code and verify geometry.
10. Test at 1024×768 iPad landscape before calling a build classroom-ready.
