HOW TO PLAY

Build a correct division route

  1. Read the highlighted long-division step.
  2. Tap a number-gate, or steer with Left/Right or A/D.
  3. Lock the gate with the button, Enter, or Space.
  4. Use the clue to repair the same step if the route breaks.

Accuracy comes first. The gate waits at the decision line if you need more thinking time.
